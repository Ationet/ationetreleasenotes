### Direct access to site location on the map

Previously, a site's location on the map was only displayed when editing the site. Starting with this version, a new item has been added to each record in the Options column of the site list view, which opens a new browser tab with Google Maps showing the site's location.

### Loyalty identifier expiration date
The following fields have been added to the Communities configuration:
- **Validate expiration date:** Checkbox that indicates whether the identifier's expiration date should be validated. When enabled, the system checks that the identifier has not expired.

- **Identifier expiration:** Allows configuring the identifier's expiration period by selecting the corresponding time unit (days, weeks, months or years).

- **Expiration period after first use:** Allows defining whether the identifier's expiration period starts counting from the date of the first transaction (accrual, redemption or discounts) performed with that identifier, instead of from the moment it is created or assigned.

### Loyalty discounts by day of the week
Added the ability to configure the days of the week on which the discounts defined in a rule are applied.

To this end, seven new checkboxes have been added to the discount rule configuration, one for each day of the week (Monday, Tuesday, Wednesday, Thursday, Friday, Saturday and Sunday). These fields allow defining the days on which the rule will be enabled to apply discounts.
