# ATIONET Console (Web Portal) - v 2.6.8300

## PROD Deployment (Aug 12, 2026)

## New Features

### Custom Message for Identification Requests

A new option has been added to Identification Models that allows administrators to configure a custom informational message. This message is displayed to Company Administrators when requesting Identifications of that model.

<img width="581" height="108" alt="image" src="https://github.com/user-attachments/assets/37b11bff-8327-4efd-b4d7-04df7f7c9150" />

### Reactivating Identifications Disabled Due to Inactivity

A new action has been added for the Company Admin role, allowing users to reactivate Identifications that were disabled due to inactivity directly from the Identifications grid in the Web Portal.

This action is available in the Options column and is displayed only when the Identification meets all of the following conditions:

* Active = No
* Deactivation Type = Inactivity
* Status = Assigned/Available

### New Filter for Vehicles/Drivers Without Assigned Rules

A new filter named "Has Rules" has been added for Company Admins. This filter allows users to view vehicles or drivers based on whether they have any rules assigned.

### Other Features or improvements:
* Improved tooltips for Quota Rules.
* Enhanced the Overall Status widget to indicate when there are vehicles or drivers without any assigned rules.

## Fixed Issues and Improvements

The following issues have been resolved:

* Fixed a tab spacing issue when creating or editing a Company Contract.
* Fixed an issue where more than 20 records were displayed per page in the Payment Methods screen.
* Fixed a page layout issue that occurred when saving a new rule with the Frequency field left empty.
* Fixed an issue where saving a record without making any changes caused an error.
