# ATIONET Console (Web portal) - v2.6.8700

## PROD Deployment (Dic 2, 2026)

### Tiered Discount Rules

A new type of discount rule is introduced, allowing different discount levels to be configured based on the amount or quantity/volume accumulated by a sub-account over a specified period.

Each rule allows multiple tiers to be defined, with a corresponding range and discount for each tier. The applicable benefit is determined according to the accumulated consumption level.

For example, a rule can be configured to grant:

- 5% discount for accumulated consumption from $0 up to $100.
- 10% discount for accumulated consumption from $100 up to $200.
- 15% discount for accumulated consumption from $200 onwards.

The configuration allows users to define whether tiers are calculated based on the accumulated amount or quantity/volume, as well as to set an accumulation reset period (days, weeks, or months). It is also possible to use the consumption from the previous period to determine the applicable discount.
