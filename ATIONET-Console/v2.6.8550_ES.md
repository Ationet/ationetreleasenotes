# ATIONET Console (Web portal) - v 2.6.8550

## Deploy en PROD (Oct 21, 2026)

### Mejoras a Fast Track
Ahora se permite crear múltiples Fast Tracks para la misma subcuenta incluso para el mismo periodo, siempre y cuando los mismos cuenten con diferentes combustibles configurados.

También se habilita el control de “Autorización por volumen”, lo que permite crear un fast track por volumen en lugar de monto. Si el mismo se encuentran activo entonces se volverán obligatorios los campos de sitio y combustible, lo que permitirá evaluar el precio base (el cual deberá estar establecido en ATIONET) para poder reservar el saldo del contrato (en importe) de acuerdo con el volumen solicitado.

## Incidentes corregidos 
Se realizaron las siguientes correcciones:
- Errores ortográficos varios.
- No se muestra el mensaje personalizado al cambiar el modelo dentro del mismo pop-up de solicitud de identificador
- Reglas de descuento periodo invalido si "fecha desde" es igual a "fecha hasta"
- Cantidad de decimales mostrados de manera incorrecta en la vista de detalles de transacciones
- Error al filtrar "Transacciones" y "Transacciones rechazadas" de Gift Card por fecha
- Orden Incorrecto en la configuración de los procesos de renovación de identificadores 
- Cuando se marca como favorito un reporte y otra vista con el mismo nombre, (por ejemplo, vehículos) solo se guarda la de administración
- El módulo de "Configuraciones de tipos de liquidación" no tiene la estrella de favoritos
- Los submódulos de Clasificadores de contratos de compañía y de sitios no tienen la estrella de favoritos
