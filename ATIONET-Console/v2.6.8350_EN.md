# ATIONET Console (Web Portal) - v 2.6.8350

## PROD Deployment (Aug 26, 2026)

## New Features

### Voucher PDF Download

A new feature called "Download PDF Package" has been added to generate a compressed (.ZIP) file containing a separate PDF file for each voucher.

This feature is available in the "Vouchers - Administration" section for Network and Company Administrators.

<img width="736" height="74" alt="image" src="https://github.com/user-attachments/assets/554e142e-e455-4603-a201-8263cae85061" />

For example, an order containing 10 vouchers will generate: 1 ZIP file • 10 individual PDF files • One PDF for each voucher included in the order.

Additionally, the "Vouchers" section now provides the option to download vouchers individually or in bulk using "Batch Actions".

### Other Features or Enhancements

* Improvents to prevent duplicate transactions.

## Fixed Issues and Improvements

The following issues have been resolved:

* Fixed an issue where the Help message for the "Frequency Start Month" field in Rules was not displayed correctly.
* Fixed an issue where more than 20 records were displayed per page in the Payment Methods screen.
* Fixed an issue when attempting to create a "Prize Warehouse" in Loyalty.
* Fixed an issue where an incorrect error message was displayed when saving a Voucher without selecting a Program.
