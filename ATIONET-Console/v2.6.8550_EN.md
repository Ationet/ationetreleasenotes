# ATIONET Console (Web Portal) - v 2.6.8550

## PROD Deployment (Oct 21, 2026)

### Fast Track Improvements

Multiple Fast Tracks can now be created for the same subaccount, including for the same period, provided that each Fast Track is configured with a different fuel type.

The "Authorization by Volume" option is also now available, allowing Fast Tracks to be created based on volume rather than monetary amount.
When this option is enabled, the Site and Fuel fields become mandatory. This allows the system to evaluate the base price (which must be configured in ATIONET) to reserve the contract balance, in monetary terms, according to the requested volume.

## Fixed Issues and Improvements

The following issues have been resolved:

- Fixed various spelling errors.
- Fixed an issue where the custom message was not displayed when changing the model within the same Identification Request pop-up.
- Fixed an issue where discount rules were considered invalid when the "From Date" was the same as the "To Date".
- Fixed an issue where the number of decimal places was displayed incorrectly in the Transaction Details view.
- Fixed an issue when filtering Gift Card "Transactions" and "Rejected Transactions" by date.
- Fixed an issue with the incorrect ordering of Identifications Scheduler configuration.
- Fixed an issue where, when marking a report and another page with the same name as favorites (e.g., Vehicles), only the Administration page was saved.
- Added the Favorites star to the "Settlement Type Configurations" module.
- Added the Favorites star to the Company Contract Classifiers and Site Classifiers submodules.
