# ATIONET Console (Web portal) - v2.6.8700

## Deploy en PROD (Dic 2, 2026)

### Reglas de descuento por tramos

Se incorpora un nuevo tipo de regla de descuentos que permite configurar diferentes niveles de beneficio en función del monto o la cantidad/volumen acumulado por una subcuenta durante un período determinado.

Cada regla permite definir distintos tramos, estableciendo para cada uno un rango y el descuento correspondiente. De esta manera, el beneficio aplicado se determina según el nivel de consumo alcanzado.

Por ejemplo, se podrá configurar una regla que otorgue:

5% de descuento para consumos acumulados desde $0 hasta $100.

10% de descuento para consumos acumulados desde $100 hasta $200.

15% de descuento para consumos acumulados desde $200 en adelante.

La configuración permite definir si los tramos se calculan en función del monto o de la cantidad/volumen acumulado, así como establecer una periodicidad de reinicio del acumulado (días, semanas o meses). También se contempla la posibilidad de utilizar el consumo del período anterior para determinar el descuento aplicable.

<br>

<img width="793" height="299" alt="config reglas desc" src="https://github.com/user-attachments/assets/25e65547-24bf-4bab-8f86-9fa49a00e083" />



Los tramos se configuran de manera independiente para cada producto (SKU), permitiendo establecer diferentes rangos y beneficios según el tipo de combustible o producto despachado, sin combinar los acumulados entre productos.

Adicionalmente, cada tramo permite establecer límites opcionales diarios o mensuales, tanto de cantidad de transacciones como de monto o volumen, para controlar la aplicación de los descuentos.

Cuando una transacción supera el límite de un tramo y alcanza el siguiente, el sistema calcula el descuento de forma proporcional, aplicando a cada parte de la operación el beneficio correspondiente al tramo respectivo.

Esta funcionalidad amplía las posibilidades de configuración de las promociones de fidelidad, permitiendo implementar esquemas de descuentos progresivos en función del consumo de cada subcuenta.

- Error al intentar exportar a excel la lista de vales filtrando por monto.
- Filtro "Solo con vales disponibles" no se aplicaba en la descarga de vales en PDF.
- Error estetico en ventana emergente para la accion de lote "Eliminar" en identificadores de flota.
