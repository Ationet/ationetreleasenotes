# ATIONET Console (Web Portal) - v 2.6.8500

## PROD Deployment (Oct 07, 2026)

### Marking ATIONET sections as Favorites

A new option has been added to each view in the ATIONET Portal to mark it as a "Favorite", displayed next to the title. Clicking the button creates a quick-access link under the "Favorites" menu. 

If the view has already been added to Favorites, clicking the button again removes the previously created quick access link.

This allows users to create quick access to the modules they visit most frequently and makes navigation through the portal easier.
